# Employee Project

This is a simple Java project created to demonstrate the use of classes, attributes, setter methods, getter methods, and user input.

## Assignment Requirements

Create an Employee class with the attributes:
- ID
- Name
- Salary

Write setter and getter methods for all attributes.

In the main method:
- Take input from the user.
- Set the values using setter methods.
- Display the employee information using getter methods.

## Files

### Employee.java

The `Employee` class contains:
- `id`
- `name`
- `salary`
- Setter methods
- Getter methods
- Default constructor
- Parameterized constructor
- Display method

### EmployeeApp.java

The `EmployeeApp` class contains the `main()` method.

It:
- Takes employee information from the user using `Scanner`.
- Stores the information using setter methods.
- Displays the information using getter methods.
