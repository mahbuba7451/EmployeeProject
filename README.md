# Employee Project

This is a simple Java project demonstrating the basic concepts of Object-Oriented Programming (OOP).

## Features

- Employee Class
- Instance Variables
- Constructor
- Display Method
- Object Creation
- Method Calling

## Files

### Employee.java
This class contains:
- Employee name
- Employee ID
- Employee salary
- Constructor
- display() method

### EmployeeApp.java
This class contains the main method. It creates an Employee object and calls the display() method.

## Example Output

Employee Name: Rahim  
Employee ID: 101  
Employee Salary: 25000.0
